# Users Dashboard

Современный и функциональный дашборд для управления данными пользователей, построенный на базе [DummyJSON API](https://dummyjson.com/docs/users).

## 🚀 Технологический стек

- **Framework:** Next.js 14+ (App Router) — для оптимальной производительности и SEO.
- **Language:** TypeScript — для надежной типизации и удобства разработки.
- **Styling:** Tailwind CSS — для быстрой и адаптивной верстки.
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/) (Radix UI) — высококачественные, доступные компоненты.
- **Data Fetching:** TanStack Query (React Query) — эффективное управление серверным состоянием, кеширование и обработка ошибок.
- **Icons:** Lucide React.
- **State Management:** URL Search Params — для сохранения состояния фильтров, поиска и пагинации в ссылке.

## ✨ Основные возможности

- **Интерактивная таблица пользователей:** 
  - Отображение ключевой информации (Имя, Возраст, Пол, Email, Компания).
  - Сортировка по колонкам (Имя, Возраст).
  - Настраиваемая пагинация (10, 20, 50 записей на страницу).
- **Поиск в реальном времени:** Мгновенный поиск пользователей по имени или email.
- **Сводная статистика:** Наглядные карточки с метриками (общее количество, средний возраст, распределение по полу).
- **Детальный профиль:** При клике на строку таблицы открывается боковая панель (Drawer) с полной информацией о пользователе (контакты, работа, финансы, дополнительные данные).
- **Синхронизация с URL:** Состояние дашборда полностью отражено в URL, что позволяет делиться конкретным видом (например, результатами поиска).
- **Адаптивный дизайн:** Интерфейс корректно отображается на мобильных устройствах, планшетах и десктопах.

## 🛠 Почему сделано именно так?

1.  **Next.js App Router:** Выбран за его мощные возможности маршрутизации и серверные компоненты, что обеспечивает отличную производительность "из коробки".
2.  **TanStack Query:** Незаменим для работы с внешними API. Он берет на себя кеширование, повторные попытки запросов и управление состояниями загрузки/ошибки.
3.  **shadcn/ui:** Позволяет создавать чистый, профессиональный интерфейс с минимальными усилиями, сохраняя при этом полный контроль над кодом компонентов.
4.  **URL-ориентированное состояние:** Это критически важно для дашбордов. Пользователь может нажать кнопку "Назад" или отправить ссылку коллеге, и они увидят те же данные.
5.  **Архитектура:** Разделение на компоненты (`UserTable`, `DashboardStats`, `UserDrawer`) делает код легко расширяемым и поддерживаемым.

## 🏁 Инструкция по запуску

Для запуска проекта вам понадобится [Node.js](https://nodejs.org/) (рекомендуется версия 18 или выше).

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <url-репозитория>
    cd users-dashboard
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите сервер разработки:**
    ```bash
    npm run dev
    ```

4.  **Откройте приложение:**
    Перейдите по адресу [http://localhost:3000](http://localhost:3000).
