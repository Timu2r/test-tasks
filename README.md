# Users Dashboard

Простое и удобное приложение для просмотра списка пользователей с использованием [DummyJSON API](https://dummyjson.com/docs/users).

## ✨ Возможности

- **Таблица пользователей:** Просмотр данных, сортировка по имени и возрасту.
- **Поиск:** Быстрый поиск по имени или email через кнопку "Search".
- **Аналитика:** Графики распределения пользователей (общее количество, пол, средний возраст).
- **Детализация:** Полная информация о пользователе в модальном окне при клике на строку.
- **URL-синхронизация:** Ссылкой на текущую страницу с фильтрами можно поделиться.

## 🚀 Технологии

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **TanStack Query** (React Query)
- **Recharts** (графики)
- **shadcn/ui** (компоненты)

## 🛠 Запуск проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Timu2r/test-tasks.git
   cd users-dashboard
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите приложение:**
   ```bash
   npm run dev
   ```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
